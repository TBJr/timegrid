# TimeGrid

Compare time zones and find fair meeting times. Drag to select, get best-overlap suggestions, share links or QR codes, and export to calendar.

## Features

- Multi-timezone 24-hour comparison grid with DST-aware conversions
- Working hours, fairness scoring, and best-overlap recommendations
- Drag-to-select meeting ranges with duration presets
- Shareable links, password-protected shares, and QR codes
- Availability polls and team presets (localStorage)
- Export to Google Calendar, Outlook, `.ics`, CSV, and JSON

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
